# Environments and the Toy Evaluator

We used this input: `(let ((n 1)) (let ((f (lambda (x) (+ x n)))) (let ((n 100)) (f 2))))`. The outer `(let ((n 1)) …)` enters the `let` branch of `eval-expr`, which calls the function `eval-let`. It evaluates the init `1` and binds `n`, creating the env `((n . 1))`. In the body, the next `let` evaluates `lambda (x) (+ x n))`, and `make-closure` returns the closure that saves ((n . 1)), and this closure is bounded to `f`. This function is responsible for capturing the defining `env`. As soon as the `lambda` is finished being evaluated, it takes the `env` `eval-expr` currently has and stores it as `(list :closure params body env)`, which can then be read later using apply-closure.

Next, the innermost `let` then binds `n = 100`, following the same branch as the outer `let` above. So, let binds `n = 100` and the env becomes `((n . 100) (f . (:closure (x) (+ x n) ((n . 1))) (n . 1)`. Next, `(f 2)` looks up `f` to get the closure, evaluates `2`, and `apply-closure` adds `x=2` to the closure’s env, resulting in `((x . 2) ( n . 1))`. The body `(+ x n)` then evaluates it, which results in `3`.
